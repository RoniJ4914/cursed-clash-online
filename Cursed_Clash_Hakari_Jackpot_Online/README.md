# Cursed Clash — Hakari Jackpot

Hakari's **Awakening key** (and domain key) at 100% awakening meter triggers Idle Death Gamble. The domain rolls up to eight times. Each spin has a 25% win probability, and success grants a 13-second Jackpot: full damage immunity and 2.65× damage. The awakening meter is spent even on a failed domain. Normal attacks, skills, rounds, domain clashes, and Yuji's existing cinematic remain.

**Music:** The actual Tuca Donca recording is copyrighted and is **not included**. To play it automatically on Jackpot, provide a copy you have permission to use, name it `tuca_donka.mp3`, and upload it alongside `index.html` and `server.js` to your hosting repository. The server streams it with HTTP Range support. Alternatively, use the in-game bottom-left file chooser to select an authorized audio file from your own device (not shared across players). The game falls back gracefully if no file is supplied.

Update both `index.html` and `server.js` on Render so the online guest hears the same jackpot cue. Each client must have the track available. Browser audio may require an initial user interaction.
