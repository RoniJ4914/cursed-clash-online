# Cursed Clash: Yuji Rhythm Bar + Supplied Secret Finisher Audio

Updated files: index.html, server.js, yuji_secret_finisher.mp3. package.json and render.yaml are unchanged.

Replace all three updated files in your GitHub repository. Render will need all three together.

When Yuji lands an M1, a centered timing indicator appears at the top. After the initial Black Flash, the green zone shows when to press B again (160–310 ms after the previous successful BF). Release B between presses. The fourth Black Flash knockout plays the supplied ~28-second recording, including the music and voice line. Audio plays on the host and is relayed as an event to the other online player. Browser sound/autoplay rules may require that players have interacted with the game first.

The MP3 is a user-provided recording; confirm you have permission to publicly distribute it before deploying to a public school-wide website.
